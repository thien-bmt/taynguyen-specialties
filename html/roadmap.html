CHIẾN LƯỢC KỸ THUẬT & E-COMMERCE

Định Hướng Phát Triển Chức Năng Đặt Hàng

Dự án được quy hoạch theo mô hình Nền tảng Thương mại điện tử Đa vùng (Multi-region E-Commerce Platform), sẵn sàng nâng cấp từ phiên bản Vanilla JS hiện tại sang hệ thống full-stack hoàn chỉnh.

Giai Đoạn 1 (Hiện Tại)

Vanilla JS & Client Cart

Tương tác thời gian thực không tải lại trang, giỏ hàng LocalStorage, form validation thông minh và hóa đơn giả lập.

Giai Đoạn 2

RESTful API & Database

Xây dựng Backend Node.js (Express) / Python (FastAPI) và CSDL MongoDB/PostgreSQL quản lý tồn kho real-time & đơn hàng.

Giai Đoạn 3

Thanh Toán & Ship API

Tích hợp cổng thanh toán VietQR động, MoMo, VNPay và kết nối API tự động tính phí vận chuyển GHN/GHTK tới 63 tỉnh thành.

Giai Đoạn 4

Admin Dashboard Nông Hộ

Trang quản trị dành riêng cho cơ sở sản xuất Tây Nguyên theo dõi doanh thu, vụ mùa thu hoạch cà phê/bơ và quản lý đơn hàng.

Tài Liệu Chi Tiết Trong Dự Án

Nội dung định hướng chi tiết và mô hình dữ liệu đơn hàng (Order Schema Model) được lưu trữ đầy đủ tại tệp tài liệu docs/project-plan.md.
